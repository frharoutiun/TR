TR Armenian Transliterator

Armenian encoding and transliteration converter

Conversion Controls

Instructions

1) Select the source and target encoding languages from the drop-down menu.
2) Paste source text in the source box.
3) Click Run and the transliterated result will appear in the target box.
4) Click Download to download the result as a .txt or .doc file.
